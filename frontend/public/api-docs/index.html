Emtehani API · v1

توثيق واجهة برمجة التطبيقات

واجهة REST لمصادقة المستخدمين وإدارة الامتحانات والجلسات والنتائج. كل نقاط النهاية المحمية تتطلب رمز وصول JWT صادراً من المنصة، وتُفرض الصلاحيات في الخادم.

Base URL: https://emtehani.runasp.net JSON / UTF-8 JWT Bearer Rate limited

البدء السريع

1. الحالة

تحقق من توفر الخدمة عبر GET /health. الاستجابة الناجحة هي 200 Healthy.

2. تسجيل الدخول

أرسل البريد وكلمة المرور إلى POST /api/auth/login للحصول على رمز وصول ورمز تجديد.

3. استدعاء API

أضف Authorization: Bearer <token> إلى كل طلب محمي. لا تضع الرمز في الرابط.

المصادقة

تسجيل الدخول متاح للطلاب والمدرسين عبر البريد الإلكتروني وكلمة المرور. رمز الوصول JWT صالح لمدة 8 ساعات، ورمز التجديد صالح لمدة 30 يوماً ويُدوَّر عند كل استخدام. لا توجد حالياً خدمة OAuth 2.0 / OpenID Connect ولا تسجيل عملاء ديناميكي.

POST /api/auth/login
Content-Type: application/json

{ "email": "you@your-domain.com", "password": "********" }

200 OK
{ "token": "<jwt>", "refreshToken": "<opaque>", "expiresAtUtc": "2026-10-30T18:00:00Z", "role": "Student" }
GET /api/exams?page=1&pageSize=10
Authorization: Bearer <jwt>
لا ترسل كلمة المرور إلى أي طرف ثالث، ولا تحاول أتمتة تسجيل الدخول باستخدام كلمات مرور محفوظة. لا يوجد حالياً تفويض للوكلاء أو تدفق client-credentials.

الحدود والأخطاء

حدود المعدل

120 طلباً/دقيقة لواجهات API، و60 طلباً/دقيقة لمسارات المصادقة، و10 محاولات/دقيقة لكل مستخدم لإدخال الأكواد. الاستجابة 429 تتضمن Retry-After.

صيغة الخطأ

أخطاء API بصيغة application/problem+json مع title وstatus وtraceId. لا تُعاد تفاصيل داخلية أو أسرار.

CORS

مسموح فقط لأصل الواجهة المحدد في بيئة الخادم (FrontendOrigin). لا تُستخدم نطاقات مفتوحة (*) لواجهات API.

الحجم والوقت

الحد الأقصى لحجم الطلب 2 ميجابايت. استخدم GET مع الاستعلامات المرقّمة (page, pageSize) للقوائم الكبيرة.

الخصوصية والوصول

  • كل طلب محمي يُشتق منه هوية المستخدم من JWT مُتحقق منه؛ لا تُقبل هوية من جسم الطلب.
  • المدرس لا يصل إلا إلى امتحاناته والطلاب المرتبطين به. الطالب لا يصل إلا إلى محاولاته ونتائجه المفرج عنها.
  • بيانات الطلاب والمدرسين والامتحانات والإجابات والنتائج ليست محتوى عاماً ولا تُدرج في Sitemap أو ملفات Discovery.
  • لا توجد مفاتيح API أو رموز تجديد أو أسرار في أي ملف ثابت أو مستودع.
