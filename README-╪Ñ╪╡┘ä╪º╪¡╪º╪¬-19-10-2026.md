# إصلاحات منصة امتحاني — 19 أكتوبر 2026

## ما تم تعديله
- منع إصدار JWT عند تسجيل الدخول إذا لم يكن البريد الإلكتروني مؤكداً؛ تظهر رسالة توضح ضرورة تأكيد البريد أولاً.
- إضافة اسم المدرس إلى بيانات قائمة الامتحانات وعرضه كعمود في جدول الامتحانات.
- تسلسل عمليات حفظ الإجابات وتسليم الامتحان داخل معاملة SQL Server بمستوى Serializable، وإزالة تكرار السؤال داخل طلب الحفظ، وجعل إعادة طلب التسليم بعد نجاحه آمنة (Idempotent).
- منع الحفظ التلقائي من بدء طلب جديد أثناء وجود حفظ سابق أو أثناء التسليم، وانتظار الحفظ الجاري قبل تسليم الامتحان.

## مهم قبل التشغيل
- تأكد من ضبط إعدادات SMTP في `backend/Emtehani.API/appsettings.json` أو User Secrets/Environment Variables حتى تصل رسالة تأكيد البريد. القيم الفارغة في `Email:SmtpHost`, `Email:From` وبيانات الدخول تمنع إرسال الرسائل.
- بعد استبدال ملفات المشروع، أوقف الـ API والـ frontend ثم شغلهما من جديد.
- لم يتم تنفيذ `dotnet build` أو `npm run build` في بيئة تجهيز الملف لعدم توفر .NET SDK وعدم وجود `node_modules`؛ لذلك يجب تشغيل الاختبارات محلياً قبل النشر.
- لا تحذف قاعدة البيانات الحالية. التعديلات لا تتطلب حذفها أو إعادة إنشائها.
