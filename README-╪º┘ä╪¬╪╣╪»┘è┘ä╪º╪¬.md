# تحديثات منصة امتحاني

## ما تم تحديثه
- محرر إنشاء الامتحان يدعم اختيار نوع السؤال: اختيار من متعدد، صح/خطأ، إجابة قصيرة، ومقالي.
- سؤال الاختيار من متعدد يعرض أربع خانات مرتبة في صفين على الشاشات الكبيرة، ويمكن تحديد الإجابة الصحيحة من دائرة بجوار كل اختيار.
- إعداد مدة الامتحان وعدد المحاولات والسماح باستكمال محاولة بعد فقدان التركيز.
- إضافة واجهات Modal لتأكيد تسليم الامتحان ورسائل النجاح/النسخ ومنح المحاولة الاستثنائية بدلاً من نوافذ المتصفح المعتادة.
- إضافة مؤشرات تحميل هيكلية عند تحميل قائمة الامتحانات، وحالات تحميل للأزرار الأساسية.
- إضافة إجراء للمدرس لمنح محاولة استثنائية واحدة من صفحة نتائج الامتحان. عند منحها لمحاولة مفتوحة تم رصد مغادرتها، تُغلق المحاولة كمتوقفة وتُتاح محاولة جديدة.
- إخفاء الدرجة والإجابات الصحيحة عن الطالب حتى تكون حالة المحاولة `Submitted` أو `Reviewed`، وإظهار النتيجة بعد مراجعة الأسئلة المقالية واعتمادها.
- تحسين رسائل أخطاء الطلبات لتكون مفهومة للمستخدم بدلاً من عرض تفاصيل تقنية.
- تسجيل محاولات النسخ واختصارات لقطات الشاشة المرصودة، وتعطيل قائمة الزر الأيمن والنسخ داخل شاشة الامتحان.

## ملاحظات مهمة
- صفحات الويب لا تستطيع منع تصوير الشاشة على مستوى نظام التشغيل أو بكاميرا خارجية بصورة مضمونة. إجراءات الواجهة الحالية تمنع بعض الاختصارات/النسخ وتُسجل أحداثاً مرصودة فقط، ولا يصح اعتبارها دليلاً قاطعاً على الغش.
- التحقق من بناء الواجهة و.NET لم يكتمل في بيئة العمل الحالية: حزمة Vite المرفقة لم تستطع تحميل الـ native binding، وأداة `dotnet` غير متاحة هنا. بعد فك الضغط على جهاز التطوير، نفّذ `npm ci` داخل `frontend` ثم `npm run build`، ونفّذ `dotnet build` داخل مشروع `backend` قبل التشغيل.
- عند تغيير نموذج قاعدة البيانات مستقبلاً، أنشئ migration وطبّقها على قاعدة البيانات. التعديلات الحالية تستخدم خاصية `IsExceptionAttempt` الموجودة مسبقاً ولا تضيف عموداً جديداً.
