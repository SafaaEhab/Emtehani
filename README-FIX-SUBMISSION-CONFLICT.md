# إصلاح تعارض تسليم الامتحان

- أصبح طلب `POST /api/submissions/{id}/submit` يستقبل أحدث الإجابات مع طلب التسليم ويحفظها ويقيّمها داخل نفس المعاملة.
- الواجهة ترسل الإجابات الحالية مباشرةً مع التسليم، بدل الاعتماد على طلب حفظ منفصل قبل التسليم.
- التسليم التلقائي يرسل كذلك الإجابات الحالية.

## التشغيل
1. أوقف الـ API والواجهة القديمة تمامًا.
2. فك الضغط في مجلد جديد.
3. من مجلد `backend` نفّذ `dotnet build Emtehani.slnx` ثم شغّل API.
4. من `frontend` نفّذ `npm install` (إن لزم) ثم `npm run dev`.
5. اختبر بامتحان جديد. لا تحذف قاعدة البيانات.

لم يتم تشغيل build داخل بيئة تجهيز الملف لعدم توفر .NET SDK هنا.
