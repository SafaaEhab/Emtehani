# امتحاني — Full Stack (ASP.NET Core + React)

مشروع محسّن لمنصة امتحانات عربية، مفصول إلى Backend وFrontend مع Clean Architecture بأربع طبقات.

## محتويات الحزمة
- `backend/Emtehani.Domain`: كيانات المجال.
- `backend/Emtehani.Application`: عقود الطلبات والاستجابات والواجهات.
- `backend/Emtehani.Infrastructure`: EF Core وSQL Server وتوليد JWT.
- `backend/Emtehani.API`: REST API، Swagger، JWT، CORS، rate limiting وhealth check.
- `frontend`: React + Vite + واجهة عربية RTL متجاوبة.

## المتطلبات
- .NET 10 SDK
- Node.js 20+
- SQL Server (أو عدّل connection string)
- PowerShell أو Terminal

## الإعداد والتشغيل
1. أنشئ سر JWT طويلًا، ولا تستخدم قيمة التطوير في الإنتاج.
2. عيّن متغير البيئة `Jwt__Key` (أو `JWT_KEY`) بقيمة سرية طويلة.
3. عيّن `ConnectionStrings__DefaultConnection` لاتصال SQL Server.
4. لا يحتاج إنشاء حساب المدرس إلى كود دعوة. اختر نوع الحساب «مدرس» أثناء التسجيل.
5. من مجلد `backend`:
   ```bash
   dotnet restore Emtehani.slnx
   dotnet tool install --global dotnet-ef
   # طبّق الـ Migration الموجودة في المشروع على قاعدة البيانات
   dotnet ef database update --project Emtehani.Infrastructure --startup-project Emtehani.API
   # لإنشاء Migration جديدة فقط بعد تعديل الكيانات
   # dotnet ef migrations add DescribeYourChange --project Emtehani.Infrastructure --startup-project Emtehani.API
   dotnet run --project Emtehani.API
   ```
   Swagger على `/swagger`، والفحص الصحي على `/health`.
6. من مجلد `frontend`:
   ```bash
   cp .env.example .env
   npm install
   npm run dev
   ```
   افتح عنوان Vite المعروض، غالبًا `http://localhost:5173`.

## نقاط يجب استكمالها قبل الإنتاج
- لكل امتحان كود دخول فريد من 6 أرقام يُنشأ تلقائيًا عند الإنشاء. يجب نشر الامتحان قبل أن يتمكن الطالب من الدخول بالكود.
- أضيفت اختبارات وحدات لتطبيع الإجابات، وGitHub Actions للبناء والاختبارات. ما زالت اختبارات التكامل، وإدارة الأسرار عبر Vault، والنسخ الاحتياطية والمراقبة مطلوبة قبل الإنتاج.
- لا يزال يلزم تشغيل build واختبارات فعلية في بيئة .NET/Node، ثم مراجعة التدفق الكامل على قاعدة بيانات تجريبية قبل الإنتاج.
- تصحيح الإجابة القصيرة يدعم تطبيع المسافات والتشكيل وقبول أكثر من إجابة صحيحة باستخدام `|` أو `;`.
- لا تعتبر رصد فقدان التركيز دليلًا قاطعًا على الغش؛ هو مؤشر فقط.
- أضيف endpoint `/api/exams/{id}/review` وربط بواجهة مراجعة المقالات في React.
- راجع توافق إصدارات حزم .NET مع إصدار SDK المثبت في بيئتك. لم يتم تشغيل build أو اختبارات في بيئة إنشاء الحزمة.
